# Аккумуляторы базы и быстродействие

В окне **Оборудование → База → Аккумуляторы базы** можно изменить количество
и типы модулей, затем нажать **Применить без перезапуска**. Поддерживается до
1000 аккумуляторов суммарно. Ограничение батарей отдельного дрона не изменено.

База должна стоять; дроны могут продолжать свои рейсы. Текущий грунт, время,
задания, резервы, запасные батареи и статистика сохраняются. Добавленные модули
поступают пустыми: растёт ёмкость, а имеющаяся энергия остаётся прежней.
Например, переход с 6 на 10 модулей по 5 кВт·ч увеличивает ёмкость с 30 до
50 кВт·ч. Если перед установкой было 24 кВт·ч, после установки останется
24 кВт·ч, то есть 48% новой ёмкости.

Масса каждого модуля входит в массу базы и потребление привода при переезде.
Удерживаемые батареи сохраняют свои идентификаторы. Снятые модули удаляются
из инвентаря, а их масса и доля энергии учитываются как внешний вывоз.
Замена типа создаёт новые пустые экземпляры. Снять зарезервированный модуль
или изменить аккумуляторы движущейся базы нельзя. Некорректная операция
отклоняется до изменения состава и балансов.

Модули базы работают на общей шине с общей моделью состояния заряда. Они
не занимают отдельные зарядные слоты сменных батарей дронов и «Крота».
Увеличение ёмкости не увеличивает площадь панелей, мощность инвертора или
мощность зарядки посадочных мест. На основном экране и в инвентаре видны
текущая энергия и новая полная ёмкость. Сохранённая конфигурация содержит
новый состав для последующих запусков; это не снимок текущих зарядов.

## Что ускорено

Профилирование выявило повторный поиск площадки выгрузки для уже
зарезервированных контейнеров. Диспетчер теперь сохраняет назначенный маршрут
до отмены задания. При отмене резерв освобождается и место ищется заново.
Проверки фактической вместимости при выгрузке и перелёт с грузом на другую
площадку сохранены. Это также предотвращает ложную остановку из-за
недоступности нового места для уже назначенного контейнера.

Для поля пыли сохраняются индексы и коэффициенты переноса, пока не меняются
ветер, шаг времени и сетка. Сам перенос, диффузия и распад сохраняют свои
численные формулы. Загрузка большой батарейной группы проверяет инвентарь
одним пакетом вместо проверки всего состава после каждого добавления.

## Измерения

Python 3.12, одна машина, последовательные прогоны без перерисовки Qt.
Реальный ETOPO1 Каттары, карта 512 м, сетка 1024², четыре стандартных дрона,
1200 модельных секунд. Медианы трёх прогонов до и после:

| Показатель | До | После |
| --- | ---: | ---: |
| Время расчёта, с | 21,518 | 6,829 |
| Фактическое ускорение времени | 55,8× | 175,7× |
| Завершённые выгрузки | 85 | 85 |
| Выемка, м³ | 3,3908998075950674 | 3,3908998075950674 |

Расчёт ускорился в **3,15 раза**. Все прежние поля полного физического отчёта
совпали точно, включая инвентарь, задания, маршруты и энергетические балансы.
Для сравнения исключены только два новых сводных поля ёмкости/числа модулей.
SHA-256 канонического отчёта записан в результатах измерений.

Дополнительно проверена конфигурация с 1000 модулями: создание симуляции
заняло 0,772 с, расчёт 180 секунд — 1,422 с. Это отдельный сценарий с большей
начальной энергией и массой; его скорость нельзя напрямую сравнивать с
длинным прогоном стандартной базы.

Полный локальный набор: **284 теста прошли за 179,77 с**. Проверены установка
во время рейсов, нулевая ёмкость, смена типов, вывоз заряда, сохранение
конфигурации, пределы интерфейса и атомарность отказа. Численный тест пыли
проверяет дробный перенос после изменения ветра и шага времени.

На том же коммите `139904d` проверки CI прошли на Ubuntu и Windows с Python
3.11 и 3.12: **по 284 теста** в каждой конфигурации. Дополнительно выполнены
запуски legacy, ATS 2.0 с обычной и строгой логистикой, автономная загрузка
реального DEM и подготовленного канала Каттары.
[Запуск CI](https://github.com/TopoLM21/Autonomous-Terraforming-Simulator-ATS-/actions/runs/39580475430),
[машинная запись результатов](ats2/base-storage-ci-results.json).

```bash
python scripts/benchmark_canal.py --steps 1200 --trials 3 --output benchmark.json
python scripts/benchmark_canal.py --steps 180 --trials 1 --base-batteries 1000 --output large-base.json

```

1000×/2000× не являются гарантированной скоростью. Вода и эрозия не добавлены.
