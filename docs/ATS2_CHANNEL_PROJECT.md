# Канал от морского берега к Каттарской впадине

```bash
git pull
python -m pip install -e ".[test]"
python -m ats --qattara
```

В обычном запуске доступна кнопка **Ландшафт / импорт DEM…**. Встроенная карта
NOAA работает без интернета; можно импортировать более подробный локальный DEM.

## Выбор маршрута и запуск

1. Включите **Рисовать маршрут (ЛКМ)** и последовательно отметьте вершины линии:
   от морского берега внутрь **нужной сухой впадины ниже 0 м MSL**. Изгибы линии
   сохраняются. Для проверки доступен **Пример: море → Каттара**.
2. Задайте **ширину плоского дна**, **глубину дна ниже моря**, береговой отступ,
   угол откосов, размер локальной карты и допустимую высоту отвала.
   Глубина **5 м** задаёт отметку **−5 м MSL**; при поверхности +200 м это
   205 м выемки, а не 5 м от текущей поверхности.
3. Нажмите **Разметить канал**. Приложение определяет морской берег на DEM,
   переносит начало **на 10 м по вашей линии на сушу** (или на заданный отступ)
   и обрезает конец до первого входа ниже 0 м **в выбранную конечную впадину**.
   Более ранняя небольшая низина не заменяет выбранную Каттару.
4. На карте появляются зелёная точка начала и оранжевая точка конца, координаты,
   высоты, длина, профиль и число рабочих участков. Размеры всего канала хранятся
   как единый проект; подробная сетка всего региона не создаётся.
5. Нажмите **Начать копание выбранного участка**. Откроется симуляция с уже
   применённым планом и начнётся работа. Повторно рисовать канаву кистью не нужно.
   База, её площадки и отвал выбираются вне проектного канала и морского грунта.
   Параметры текущего канала видны над прогрессом в основном окне.
   Текущая организация: небольшая рабочая полоса, два боковых отвала и
   переезды базы от начала выемки. [Правила и замеры](ATS2_WORKFRONT.md).
6. Откройте окно маршрута и нажмите **Переехать на следующий участок канала**,
   либо выберите номер участка и **Переехать всей группой в выбранное окно**.
   Техника, заряды, часы, рельеф и история сохраняются; движение требует энергии.
   [Порядок переезда, возврат и сохранение в пути](ATS2_SHARED_PLATFORMS.md#переезд-между-локациями).
   **Следующий участок · новая расстановка** оставлен для отдельного нового запуска.
   **Сохранить ландшафт…** записывает DEM и грунт в `.atsregion`; файл `.atsstate`
   через меню Файл включает также всю технику и текущие приказы.

Начало можно указать чуть в море: морская часть будет удалена из рабочего
маршрута. Если первая вершина уже на суше, начальное ребро продлевается назад
до берега (поиск до 50 км). Если берег в этом направлении не найден, измените
первые вершины. Последняя вершина должна находиться ниже моря в сухой впадине.
Маршрут, повторно входящий в море, отклоняется.

Береговой отступ задаёт начало земляных работ, а входной переход плавно выходит
на проектное дно. Морские ячейки защищены от выемки; при широком косом подходе
формируется береговой откос. Поэтому непосредственно у начала профиль может
быть мельче проектной отметки. Все изменения грунта выполняются физическим
движком, а не самим выбором маршрута.

## Карта и память

| Сторона локальной карты | Ячейка по умолчанию | Размер активной сетки |
| --- | --- | --- |
| 32–256 м | 0,25 м | до 1024×1024 |
| 512 м | 0,5 м | 1024×1024 |
| 1024 м | 1 м | 1024×1024 |

Шаг 1 с, масса груза, скорость копания, масса оборудования и энергопотребление
сохраняют свои физические единицы. Крупная ячейка хранит **среднюю высоту**;
подробности движения отдельного ковша мельче этой ячейки не разрешаются.
Физический радиус и вместимость установленного грейфера не увеличиваются вместе
с картой.

Постоянное хранилище ландшафта остаётся разреженным с шагом 0,25 м. Изменение
крупной активной ячейки распределяется по её мелким ячейкам с сохранением объёма.
Ранее созданные мелкие детали сохраняются; повторное сохранение того же окна
не накапливает изменение. Просмотр и разметка не создают сохранённую мелкую сетку.
Доступность грунта вычисляется вокруг ковша, а осыпание импортированного рельефа
проверяется возле потревоженных ячеек.

## Широта и солнечная энергия

На WGS84-карте широта вычисляется по **фактическим координатам базы**, включая её
локальное смещение внутри окна. При перемещении базы значение обновляется.
Поле широты в GUI становится доступным только для чтения; начальное значение
55° не подменяет координаты Египта. Для спроецированного GeoTIFF используется
преобразование CRS через rasterio.

Эта широта участвует в расчёте высоты Солнца, продолжительности дня и мощности
горизонтальных панелей. Сезон и время суток также учитываются. Это прежняя модель
ясного неба, без погоды; в тесте зимняя генерация одинакового оборудования на
30° N оказалась более чем вдвое выше генерации на 55° N.

## Командная строка

Пример файла `qattara-route.json`:

```json
{
  "coordinates": "source",
  "points": [[28.3, 31.2], [27.5, 29.5]],
  "width_m": 20,
  "depth_m": 5,
  "shore_offset_m": 10,
  "angle_deg": 35,
  "side_m": 512,
  "spoil_height_m": 20
}
```

Для WGS84 `source` означает долготу/широту. Для метрического DEM это его
исходные координаты. `coordinates: "metres"` задаёт смещения от юго-западного
отсчёта DEM в метрах, как на обзорной карте.

```bash
python -m ats --qattara --channel-route qattara-route.json
python -m ats --headless --qattara --channel-route qattara-route.json \
  --channel-section 1 --steps 10000 --json channel-report.json
python -m ats --landscape canal.atsregion --channel --channel-section 2
```

Дополнительные переопределения: `--channel-width`, `--channel-depth`,
`--shore-offset`, `--map-size`. `--save-landscape FILE` сохраняет проект и грунт
после завершения рейсов и выгрузки. Файл не сохраняется с неучтённым грузом в полёте.

## Границы модели

- Встроенный ETOPO1 имеет шаг около 1,6×1,85 км. Отступ 10 м вычисляется от
  **интерполированного берега DEM**; для действительной точности в 10 м нужен
  соответствующий исходный рельеф/береговая съёмка. Берег не скачивается из
  дополнительного интернет-сервиса.
- Морская область определяется связностью отрицательных узлов DEM с внешней
  границей. Импортируемая область должна содержать море, разделяющую сушу и
  выбранную впадину. При грубом или тесно обрезанном DEM классификация берега
  ограничена исходными данными. Расчёт воды и затопления не выполняется.
- Маршрут выбираете вы; оптимизатор траектории пока не добавлен. Оценка полного
  объёма по региональному профилю приближённая, детальная выемка в активном окне
  считается по его высотам и площади ячеек.
- Группа может физически переехать между перекрывающимися окнами одного DEM
  с сохранением общей истории, ID и зарядов. Полного автоматического streaming
  огромного мира нет. Наземный маршрут должен быть проходим; при нехватке места
  или закрытом пути группа ожидает. Отдельная кнопка **новая расстановка**
  создаёт новый запуск оборудования и не заменяет физический переезд.
- Изменение размеров/разбивки проекта создаёт новый вариант проекта. Уже
  изменённый рельеф сохраняется. Глубокий широкий канал может потребовать карты
  1024 м, большего отвала, иных батарей или оборудования: нехватка места или
  энергии блокирует работу с указанием причины.
- Грунт пока имеет свойства заданного песка; вода и водная эрозия не добавлены.

Автотесты покрывают береговой отступ, выбранную впадину, изгибы и косые подходы,
готовый план, реальную выемку, солнечную генерацию, сохранение разной детализации,
переход на следующий участок, инвентарь и балансы массы/энергии.
