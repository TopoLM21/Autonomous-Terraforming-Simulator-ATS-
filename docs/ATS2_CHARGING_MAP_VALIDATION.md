# Индивидуальные зарядные слоты и увеличенная карта

2026-10-19. Изменение существующего симулятора; гидрология и эрозия не добавлены.

## Поведение и управление

Каждый сменный физический модуль дрона и Крота имеет постоянный зарядный слот
на базе. Пока модуль установлен или перевозится, его слот пуст. После возврата
модуль заряжается в своём слоте. Резерв задания исключает зарядку. Полная батарея
сохраняется на складе и доступна для реальной механической замены.

По умолчанию четыре двухмодульных дрона с одним запасным комплектом и Крот с
двумя запасными модулями имеют **20 слотов**: 16 дроновых и 4 для Крота.
При двух запасных комплектах дронов — **28 слотов**. Индивидуальные ID неизменны
при замене; оборудование не создаётся в ходе миссии. Аккумуляторы самой базы
остаются на прежнем контуре хранения энергии.

Один слот ограничен 1,5 кВт входа и паспортным пределом модуля. Посадочные доки
сохраняют общий предел 8 кВт и получают питание первыми. Остаток мощности делится
между неполными снятыми батареями. Все потребители используют реальные панели,
общий аккумулятор и конечный инвертор базы. КПД контактной зарядки — 90%; потери
входят в баланс. Корпус, разъём и контроллер слота весят по модельному допущению
1 кг; масса добавляется к базе без дополнительной энергии.

**Склад / диспетчер → Зарядные слоты** показывает ID, положение модуля, SOC,
состояние и фактическую мощность каждого слота. Таблица строится только при её
просмотре. Для исторических сравнений доступен режим общей очереди:

```bash
python -m ats --mode logistics --map-size 128 --drone-spare-sets 2
python -m ats --mode logistics --module-charge-mode shared --module-charge-ports 4
```

Новые запуски имеют поле **64 × 64 м**, размер нового сценария настраивается
от **32 до 256 м**. Ячейка остаётся 0,25 м. При увеличении карты координаты проекта,
базы и отвала сохраняются в метрах. Загруженные файлы сохраняют свой размер;
изменить сетку сохранённого рельефа можно только новым сценарием. `Config()`
сохраняет 32 м для совместимости программных сценариев.

Карта занимает больше места в окне. Кнопки **+ / −**, колесо, **Вся карта**
меняют камеру. **F11** разворачивает карту, **Esc / F11** возвращает её в окно.
Используется тот же plot, состояние симуляции и кисти сохраняется.

## Тесты

**191 тест прошёл за 145,16 с**: Linux, Python 3.12.14, NumPy 2.5.4,
PySide6-Essentials 6.12.0. [JUnit](ats2/charging-map-tests-312.xml).
Проверки GitHub Actions на Windows/Ubuntu для этого изменения пока не запускались.

Новые проверки покрывают:

- одновременную зарядку 12 снятых модулей при прежнем числе портов 1;
- предел каждого слота, суммарную мощность 18 кВт при достаточном питании,
  ограничение инвертора до 5 кВт, независимые пределы доков и слотов;
- отсутствие заряда у пустой базы, полевых и зарезервированных батарей;
- массу оборудования, постоянство ID через настоящую замену, атомарный отказ
  при попытке закрепить второй слот за той же батареей;
- конфигурации и CLI, сохранение прежнего размера загруженного поля;
- сетки 32/64/128/256 м и запрет нецелого числа ячеек;
- настоящий Qt-ввод: колесо, F11, Esc, кнопки масштаба и мазок кистью за пределами
  прежнего поля; закрытие основного окна с развёрнутой картой;
- работу кисти, сохранение массы и JSON-планов на увеличенном поле.

CLI-прогон со свободными копателями завершён за **1132 с**, в строгой логистике
со сменами батарей — за **3861 с** (две замены дронов, одна замена Крота).

## Сравнение конфигураций

Seed 42, прежние координаты проекта, ячейка 0,25 м, лазер выключен. В логистике
четыре дрона, восемь контейнеров, два запасных модуля Крота, 20 м² панелей.

Все семь миссий завершились. Ошибка массы — **0 кг**, максимальная абсолютная
ошибка энергии — **7,16 × 10⁻⁷ Дж**. Карты 32/64 м для medium и 64/128 м для demo
дают одинаковое физическое время, массу и энергию; большие сетки требуют больше
вычислений. Для максимального поля 256 м выполнены создание мира и 10 физических
шагов с корректными балансами; полная миссия на нём отдельно не измерялась.
[Полные метрики](ats2/charging-map-comparison.json).

Индивидуальный слот устраняет очередь к разъёму, но не создаёт дополнительной
энергии. При ограниченном питании равномерная зарядка многих неполных батарей
может позже дать первый готовый комплект, чем обслуживание очереди. В medium
на исходной базе индивидуальные слоты увеличили время миссии; результат приведён
в таблице без предположения, что больше зарядных устройств всегда быстрее.
Политика питания и оборудование базы существенно влияют на производительность.
